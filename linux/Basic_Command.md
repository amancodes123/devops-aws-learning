# Linux Commands
## 1. Basic Commands
### Check current directory
```bash
pwd
```

### List files
ls

### List files with detailed information
```bash
ls -l
```

### List hidden files
```bash
ls -a
```

### List all files with detailed information
```bash
ls -la
```

### Change directory
```bash
cd directory_name
```

### Go to the home directory
```bash
cd ~
```

### Go to the previous directory
```bash
cd -
```

### Go to the parent directory
```bash
cd ..
```

### Make directory
```bash
mkdir directory_name
```

### Create multiple directories
```bash
mkdir dir1 dir2 dir3
```

### Create a file
```bash
touch file.txt
```

### Create multiple files
```bash
touch file1.txt file2.txt file3.txt
```

### Copy file
```bash
cp source destination
```

### Copy a directory
```bash
cp -r source_directory destination_directory
```

### Move file
```bash
mv source destination
```

### Rename a file
```bash
mv old_name.txt new_name.txt
```

### Remove a file
```bash
rm file.txt
```

### Remove a directory
```bash
rm -r directory_name
```

### Show file content
```bash
cat file.txt
```

### View a file page by page
```bash
less file.txt
```

### View the first lines of a file
```bash
head file.txt
```

### View the last lines of a file
```bash
tail file.txt
```

### Follow a file in real time
```bash
tail -f file.log
```

### Edit a file using vi
```bash
vi file.txt
```

### View command information
```bash
man command_name
```

### Clear the terminal
```bash
clear
```

### Display the date and time
```bash
date
```

### Display the current user
```bash
whoami
```

### Show logged-in users
```bash
who
```

### Show command history
```bash
history
```

### Find the location of a command
```bash
which command_name
```

### Find files and directories
```bash
find /path -name "filename"
```

### Search for text inside a file
```bash
grep "text" file.txt
```

### Count lines, words, and characters
```bash
wc file.txt
```

### Display disk usage
```bash
df -h
```

### Display directory/file size
```bash
du -sh directory_name
```

### Display running processes
```bash
ps
```

### Display all running processes
```bash
ps aux
```

### Display processes in real time
```bash
top
```

### Exit the terminal/session
```bash
exit
```
